# Titre : Boutique en ligne

## Sujet

Boutique en ligne permettant d’afficher sur une page web unique (Single Page Application) une liste d’articles et une liste de catégories d’articles de sorte qu’en cliquant sur une catégorie, l’application affiche uniquement les articles correspondants. L’utilisateur doit pouvoir ensuite constituer un panier d’articles simplement en ajoutant et supprimant des articles autant de fois qu’il le souhaite, puis passer commande à tout instant avec demande de confirmation. Une fois la commande validée, le panier est vidé.

Projet Web utilisant un fichier JSON pour les données, en HTML / CSS et Javascript.

```
git clone  https://github.com/severinehmfms/BoutiqueEnLigne.git
```

## Lancer le projet avec un serveur local python

Le plus facile pour lancer un serveur local est encore d'utilisé **python** et plus spécifiquement : **http.server**.

Il ira directement ouvrir le fichier **index.html** du répertoire où le serveur est lancé

### Windows

```cmd
python -m http.server 8000
```

### Linux

Dans cette commande le port 8000 est utilisé mais cela peut très bien être par exemple **3000** 

```bash
python3 -m http.server 8000
```

## voir le projet dans le navigateur

Il suffit de ce rendre à l'adresse suivante: (à adapter si un port différent du 8000 est choisi) :

<http://0.0.0.0:8000>
