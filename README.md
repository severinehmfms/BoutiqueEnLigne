Titre : Boutique en ligne

Sujet : Boutique en ligne permettant d’afficher sur une page web unique (Single Page Application) une liste d’articles et une liste de catégories d’articles de sorte qu’en cliquant sur une catégorie, l’application affiche uniquement les articles correspondants. L’utilisateur doit pouvoir ensuite constituer un panier d’articles simplement en ajoutant et supprimant des articles autant de fois qu’il le souhaite, puis passer commande à tout instant avec demande de confirmation. Une fois la commande validée, le panier est vidé.

Auteurs : Séverine Hori Maitrehut, Alban Martel

Description : Projet Web utilisant un fichier JSON pour les données, en HTML / CSS et Javascript.
